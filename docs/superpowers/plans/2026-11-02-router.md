# Router Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `run_agent(model="auto")` picks the real endpoint for a job from a d3-scored brief and a calibrated scorecard, queues it with every other job through a database-backed admission gate, records why, and learns from gates and verdicts; a second MCP server and two CLI commands control and inspect it.

**Architecture:** A `backend: router` entry in `models.yaml` makes dispatch do one extra step (resolve brief → d3 scores → live facts → shortfall selection → enqueue on the chosen real endpoint); from admission on the job is an ordinary job. Admission (partitioned slots, pooled KV tokens, a throughput curve) and the queue are rows in the existing SQLite file so every server process shares them. The scorecard is rows (endpoint × served id) of cells (dimension × language) seeded by a CLI-run calibration and corrected by mechanical gates after every job and by an explicit verdict tool. New code lives in `src/localagents/router/`; `registry.py`, `server.py`, `runner.py`, `db.py` and `__init__.py` are touched at named seams.

**Tech Stack:** Python 3.12, sqlite3 (WAL, `BEGIN IMMEDIATE`), httpx, the existing FastMCP server pattern (`mcp.tool()`), pytest. The d3 server command needs the `router` extra: `torch`, `transformers==5.17.0` (what `vllm-sr/d3-mini` loads with `trust_remote_code=True`).

**Spec:** `docs/superpowers/specs/2026-11-02-router-design.md` (every § below refers to it). The calibration SET (which probes, nominal timings, draft definitions, thresholds) is its own spec; this plan builds the runner and ships a minimal built-in set so the gate and the runner are testable.

## Global Constraints

- Nothing from the operator's fleet in package code, defaults, README or the example config (no `ai1`, `dgx*`, `10.0.0.*`, model file paths). Fixtures under `tests/fixtures/router/` are the only captured data and are scrubbed.
- A worktree checkout never opens the default state dir: every lane sets `XDG_STATE_HOME` and `LOCALAGENTS_DB` (`db.state_dir()` refuses otherwise). Scratch under `t/`, never `/tmp`. No `git stash`.
- The router is never on the wire (§2, §4): no proxy, one decision per job, the session's requests go to the chosen row.
- Only `decision_url` is required on the router entry (§12). Defaults named in this plan (`tolerance=1.0`, `divert_after_min=10`, thresholds, weights, band tables) are module constants a later calibration spec may revise; each is defined once and imported.
- Plain `CREATE TABLE` in a new migration step `_V10` (no `IF NOT EXISTS`); `SCHEMA_VERSION` becomes 10.
- Every router error returned from a tool is a dict with `error` and `message` like `ModelUnavailable.to_dict()`, never a raised exception.
- Public prose (README row, `docs/router.md`): no "X, never Y" slogans, no bold-label inventory paragraphs.

## Review Focus

1. **Two server processes admit into the last slot at once.** Expected: exactly one admits; the other stays queued. Pinned in Task 5 (`test_two_connections_race_for_one_slot`).
2. **The chosen endpoint goes down while the job is queued.** Expected: the job is re-selected onto another row or refused with a reason, never lost in `queued`. Pinned in Task 8 (`test_queued_job_reroutes_when_its_row_goes_down`).
3. **A pointer brief whose file is missing.** Expected: `run_agent` returns `brief_unresolved` with the path, no job created. Pinned in Task 3 (`test_resolve_brief_missing_file_is_an_error`) and Task 8.
4. **A row whose served id changed since calibration.** Expected: a new row, uncalibrated, filtered with `uncalibrated`; the old row archived, its history kept. Pinned in Task 6 (`test_served_id_change_archives_the_row`).
5. **d3 answers with every axis below threshold.** Expected: all surviving rows tie, the tie-break decides, the ticket lists every axis `undetermined`, a later verdict updates no capability cell. Pinned in Task 7 (`test_all_undetermined_falls_to_tie_break`) and Task 9 (`test_verdict_skips_undetermined_axes`).
